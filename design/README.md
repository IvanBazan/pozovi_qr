# Исходники и макеты

- `design/` — макеты и референсы (PNG, PDF, экспорт из Figma). В сборку не попадают.
- `nginx/static/assets/` — файлы, которые реально используются на страницах: логотипы, картинки, шрифты.
  Отдаются как https://pozoviqr.ru/assets/<имя>
- `nginx/static/favicon.ico` — фавикон домена.
